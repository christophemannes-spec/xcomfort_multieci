# xComfort Multi-ECI

Home Assistant App repository containing a fork of
[karloygard/xcomfortd-go](https://github.com/karloygard/xcomfortd-go)
that fixes a datapoint-number collision affecting multi-ECI (multi-floor)
xComfort setups. See [`xcomfort_multieci/README.md`](xcomfort_multieci/README.md)
for the full technical explanation, and
[`xcomfort_multieci/UPSTREAM.md`](xcomfort_multieci/UPSTREAM.md) for the
origin reference.

## Adding this repository to Home Assistant

Settings -> Add-ons -> Add-on Store -> (top right menu) -> Repositories ->
add this URL: https://github.com/christophemannes-spec/xcomfort_multieci
Then install **xComfort Multi-ECI** from the store.
